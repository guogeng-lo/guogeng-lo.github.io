# 終焉之刃（MyDungeonGame）素材

使用者提供的素材，給新增作品頁用。

## 基本資料

- 自己做好玩的遊戲，不是課堂作業，2025年做的
- Java Swing，原始碼不公開
- 沒有用別人的素材

## 玩法

- 2D平台跳躍，目標是一路往上爬到頂峰，畫面上會顯示「距離頂峰」還有幾公尺
- 平台有很多種：會彈的、會移動的、踩了會碎的、有尖刺的
- 小怪有會衝過來的和會射子彈的
- 一路上可以拿到二段跳和光束槍，有營火當存檔點，起點附近有一個直接去打王的「魔王捷徑」（遊戲裡會提示先拿二段跳和槍再去）
- 進入「魔王之間」後打深淵領主·薩麥爾：會放地火、震波、從天上落下的審判之劍等攻擊
- 打贏後先出現NIGHTMARE SLAIN，再進一段可以亂打的「狂歡紓壓時間」，最後是結算畫面（通關時間、最終分數、剩下的血瓶）
- 操作：方向鍵移動和跳躍、下+上跳下平台、Z衝刺、X斬擊、C射擊、V喝血瓶

## 程式架構（給技術筆記用）

- 一個Java檔，大約1,500行
- 主畫面是一個JPanel，用Swing的Timer每16毫秒更新一次再重畫，大約每秒60格
- 遊戲狀態有：選單、遊戲中、打贏後的狂歡時間、死亡、結算
- 所有東西（玩家、子彈、斬擊、道具、敵人、王、特效）都繼承同一個GameObject，每一格輪流呼叫update再畫出來
- 平台也是用繼承分出彈跳、移動、易碎、尖刺幾種
